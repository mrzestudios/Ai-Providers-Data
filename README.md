# AI Providers Directory 🚀

A comprehensive, curated index of artificial intelligence API providers, OpenAI-compatible base URLs, authentication headers, and primary model configurations. 

This repository serves as a quick-reference guide and machine-readable dataset for developers building multi-LLM applications, custom API gateways, or setting up dynamic routing engines like **LiteLLM**, **OpenWebUI**, or **LangChain**.

## 📌 Features
- **Standardized Base URLs:** Quick copy-paste endpoints for commercial and open-weights hosts.
- **Authentication Cheat Sheet:** Exact header keys required (`Authorization`, `x-api-key`, etc.).
- **Model References:** Up-to-date tracking of flagship models from major vendors.
- **Developer Friendly:** Available in a clean text layout and easily parseable for automation.

## 🛠️ Usage
Perfect for configuring environment files (`.env`), setup scripts, or multi-provider API clients.
